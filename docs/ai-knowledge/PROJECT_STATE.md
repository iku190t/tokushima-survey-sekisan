## 現時点で検証済みではない範囲

- **状態: 観察**
- 令和4～7年度は技術者単価プリセットのみで、各年度の徳島県歩掛・経費率を含む完全マスターではない。
- 徳島県以外の46都道府県は選択肢の土台だけで、検証済み完全マスターは未収録である。全国で実計算可能になったという意味ではない。
- 都道府県の公開方法は統一されていない。公式サイトで全編PDFを公開する自治体、国基準との差分だけを公開する自治体、市販版と県補足資料を組み合わせる自治体、CD貸出・窓口閲覧を行う自治体が確認されている。このため国交省版や徳島県版を他県へ複製して完全マスター扱いしない。
- 将来年度・他県は、公式資料と正解積算で検証後に `data/master-catalog.json` へ登録した場合だけ自動取得対象になる。行政サイトを直接スクレイピングして自動確定はしない。
- 実案件ごとの特記仕様、貸与条件、成果検定費、航空運航条件は自動的に確定できない。
- 帳票のA4印刷CSSと生成処理は静的試験済みだが、現行スナップショットの全帳票について実PDFの目視検査記録はない。
- Google Analyticsは公開HTTPS版で利用者が許可した場合だけ読み込み、ローカル`file:`実行では送信しない。公開版で拒否選択の保持は実ブラウザー検証済み。許可時のGA管理画面への着信確認は未検証である。
- 初回コミット作成前の正常基準は `B-2026-08-22-01`、Git導入後の正常基準は `B-2026-08-22-02` である。
