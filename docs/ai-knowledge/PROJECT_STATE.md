## 現時点で検証済みではない範囲

- **状態: 観察**
- 令和4・5年度は技術者単価プリセットのみで、歩掛・経費率を含む年度マスターではない。令和6～8年度は全国標準参考マスターを収録する。
- 徳島県・広島県以外の45都道府県も全国標準参考で計算できるが、県独自歩掛、労務・材料・市場・機械単価、補正、適用通知は未検証・未反映であり、県版検証済み完全マスターではない。
- 都道府県の公開方法は統一されていない。公式サイトで全編PDFを公開する自治体、国基準との差分だけを公開する自治体、市販版と県補足資料を組み合わせる自治体、CD貸出・窓口閲覧を行う自治体が確認されている。このため国交省版や徳島県版を他県へ複製して完全マスター扱いしない。
- 将来年度・他県は、公式資料と正解積算で検証後に `data/master-catalog.json` へ登録した場合だけ自動取得対象になる。行政サイトを直接スクレイピングして自動確定はしない。
- 実案件ごとの特記仕様、貸与条件、成果検定費、航空運航条件は自動的に確定できない。
- 帳票のA4印刷CSSと生成処理は静的試験済みだが、現行スナップショットの全帳票について実PDFの目視検査記録はない。
- 設計・調査の標準歩掛は網羅収録していない。原資料で数値確認した「設計留意書の作成」だけを確認済みプリセットとし、その他は作業名・職種・人工を明示入力する。市場単価、機械、材料、運搬、仮設、旅費、案件固有費用は積上げと照合が必要である。
- 設計・調査の総合帳票は生成結線を静的試験したが、ブラウザー印刷で保存した実PDFの全ページ目視確認と匿名化済み正解積算との一致確認は未完了である。
- PDF・OCR取込は匿名合成資料で検証した範囲であり、発注機関ごとに異なる実資料の表組み、縦書き、低解像度写真、手書き、傾き、複数段組、押印重なりを網羅していない。OCR候補は正解値ではなく元資料照合が必要である。
- PDFクリック取込は文字入り匿名合成PDFで実操作済み。OCR行座標は固定値試験済みだが、画像PDFのOCR結果を実ブラウザー上でクリックして反映する一連の操作は未検証である。
- 業務基本情報の抽出も匿名合成原文で検証した範囲であり、表のセル分割、複数候補、同名ラベル、住所改行、契約変更履歴などの実様式は未検証である。
- 公式案件検索は候補照合であり、官公需情報ポータルに未収録・公開終了・後日訂正された資料、同名案件、番号表記ゆれを自動的に解決しない。実案件での再現率・誤一致率、発注機関原ページの最新版確認は未検証である。
- 公開版は第三者CORS中継を使用せず、公式API XMLの保存・読込が必要である。API仕様変更、リンク切れ、発注機関ごとの添付資料命名差は未検証である。
- Google Analyticsは公開HTTPS版で利用者が許可した場合だけ読み込み、ローカル`file:`実行では送信しない。公開版で拒否選択の保持は実ブラウザー検証済み。許可時のGA管理画面への着信確認は未検証である。
