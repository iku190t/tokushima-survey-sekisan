# 外部知能エントリーテンプレート

以下を複製して使用する。空欄や「たぶん」を残したまま検証済みにしない。

```markdown
## <ID> <短い題名>

- 状態: 観察 / 再現済み / 検証済み / 仮説 / 廃止
- 記録日: YYYY-MM-DD
- 対象領域: 計算 / マスター / UI / 帳票 / 保存 / 運用
- 対象バージョン: コミットID、またはベースラインIDとSHA-256
- 主張: 1つの検証可能な文で記載

### きっかけ

何を調べる必要があったか。会話文を仕様として転載しない。

### 観察

ファイル、ログ、画面、原資料で直接確認した内容。

### 再現手順

1. 前提条件
2. 入力
3. 操作またはコマンド
4. 実際の結果
5. 期待する結果

### 仮説

未検証の原因推定。なければ「なし」。仮説だけで修正しない。

### 検証

- 原資料:
- テスト:
- 期待値:
- 実行結果:
- 検証日:

### 判断・修正理由

採用した判断と、採用しなかった案の理由。

### 再発防止

追加した固定値試験、入力制限、警告、確認手順。

### 昇格管理

- 独立確認回数: 1
- 証拠ID:
- 常設ルールへの昇格: しない / 候補 / 昇格済み
- 昇格理由:

### 廃止情報

- 廃止日:
- 廃止理由:
- 後継ID:
```

## 記録禁止

- APIキー、パスワード、認証情報、秘密のURL
- 個人名、住所、電話番号、メールアドレス
- 顧客名、案件名、実案件の数量・単価・契約金額
- 会話内容の丸写し
- 再現または検証できない断定

匿名化が必要な検証データは、実案件を転記せず、同じ境界条件を満たす最小の合成データに置き換える。
