# 検証済みの設計判断

会話上の希望ではなく、現行コード、原資料照合記録、試験で確認できた判断だけを記録する。

## D-001 標準数量総額と1単位当り単価を分離する

- 状態: **検証済み**
- 判断: 標準歩掛の総額を、そのまま1点・1km等の単価として扱わない。標準数量で除し、所定の端数処理後に積算数量を掛ける。
- 代表例: 2級基準点測量・新点10点・伐採有りは、標準10点直接費3,448,507円、1点単価344,800円、10点直接作業費3,448,000円。
- 証拠: `規定再監査報告.md`、`調査・実装メモ.md`、`tests/test-engine.js`
- 昇格: プロジェクト判断。一般ルールへの追加確認回数は管理していない。

## D-002 精度管理費の対象判定は作業コードで行う

- 状態: **検証済み**
- 判断: 作業名の部分一致で精度管理対象を推定しない。公式作業コードと項目別設定を使用する。
- 理由: 「河川」「水準」など名称の重なりで誤分類が発生した。
- 証拠: `規定再監査報告.md`、`tests/test-engine.js`

## D-003 過去年度単価と完全過去年度マスターを区別する

- 状態: **検証済み**
- 判断: 令和4・5年度プリセットは技術者単価の公表値記録であり、完全過去年度マスターではない。比較用マスターを作る画面は廃止する。令和6～8年度は歩掛・率・技術者単価を同年度で組んだ「全国標準参考」と、原資料を地域別に照合した「県版検証済み」を明確に区別する。
- 廃止: 「令和8年度歩掛＋過去年度技術者単価」を利用者が作成する比較UI。正式年度と誤認しやすいため2026-08-22に廃止した。
- 証拠: `data/official-role-prices.js`、`app.js`、`index.html`、`tests/test-role-prices.js`、`tests/test-ui-static.js`

## D-004 数量精度は単位別に制限する

- 状態: **検証済み**
- 判断: 点・箇所・回等の離散量は整数、km・km²・時間等の連続量は小数第3位までとする。入力、貼付け、JSON読込みで同じ正規化を使う。
- 証拠: `engine.js`、`app.js`、`tests/test-engine.js`、`tests/test-ui-static.js`

## D-005 帳票金額は画面と同じ計算結果から生成する

- 状態: **検証済み（静的結線）**
- 判断: 見積書、総括表、業務費内訳書、単価・歩掛内訳書、積算条件書は `calculateEstimate` の結果から生成し、帳票専用の別計算を持たない。印刷直前にも再生成する。
- 証拠: `app.js`、`tests/test-ui-static.js`
- 未検証: 全帳票の実PDF目視品質。検証完了まではレイアウトの正常ベースラインへ昇格しない。

## D-006 起動時は新規画面とし、前回データは明示操作で復元する

- 状態: **検証済み（静的結線）**
- 判断: 起動時の `estimate` は必ず `emptyEstimate()` で作る。ローカル自動保存データは復元候補として保持し、「前回データを復元」を押した場合だけ表示する。
- 保護: 未操作で閉じる場合は空の新規データを保存せず、前回データを上書きしない。
- 区別: 「読込」はJSONファイルの読込み、「前回データを復元」はブラウザー内自動保存の復元とする。
- 証拠: `app.js`、`index.html`、`tests/test-ui-static.js`
- 未検証: 実ブラウザーでのローカルストレージ復元操作。手動確認が完了するまでは完全検証へ昇格しない。

## D-007 公開者・免責・応援・アクセス解析を画面上で明示する

- 状態: **検証済み（静的結線）**
- 判断: 公開画面のフッターは「Ez積算」ボタン1個だけにする。押すと、制作会社・公式サイト・OFUSE応援・ゲスト送信案内・免責・プライバシー設定を1つの統合ダイアログで表示する。参考試算で公式ソフトではない旨、`DISCLAIMER.md`、積算条件書と全帳票フッターの公式資料照合注意も維持する。
- 廃止: フッターに「制作会社」「公式サイト」「応援のご案内」「免責・プライバシー」を個別表示し、応援と免責を別ダイアログに分ける方式。導線が重複するため2026-08-22に廃止した。
- Analytics: GA4測定IDは既存Ezアイズ製品で公開使用中の`G-88B9YPJXWP`とし、公開HTTPS版で利用者が許可した場合だけ読み込む。広告保存・広告シグナルは無効にし、積算入力値を送る独自イベントを実装しない。ローカル`file:`実行では送信しない。
- 理由: 無料公開時の作成主体・非公式性・検証責任・外部送信を、利用前に利用者が確認できるようにするため。
- 証拠: `index.html`、`analytics.js`、`app.js`、`DISCLAIMER.md`、`tests/test-ui-static.js`
- ローカル検証: フッターの表示・ボタンが「Ez積算」1個、フッター直リンク0件、ダイアログ1個であること、統合ダイアログに制作・公式サイト・応援・免責・プライバシー設定が揃うこと、ブラウザー警告・エラー0件を確認した。
- 公開検証: GitHub Pagesビルド`1167136725`で、フッター「Ez積算」1ボタン、統合ダイアログの制作・公式サイト・応援・免責・プライバシー設定、ブラウザー警告・エラー0件を確認した。
- 未検証: 許可時のGA管理画面への着信、全端末での表示。

## D-008 全国対応は全国標準土台と県別検証済み上書きで行う

- 状態: **検証済み（基盤）**
- 判断: 積算地域と積算年度を別々に選択する。国交省公表の標準歩掛・技術者単価による令和6～8年度マスターを47都道府県共通の参考土台として選択可能にする。県の同年度原資料を照合済みの場合だけ県版検証済みマスターを優先する。
- 廃止: 完全マスター未収録県を選択不能にする方式。全国標準共通部分まで利用できなくなり、市販ソフトの標準単価セット型の使い方から離れるため、2026-08-22に廃止した。
- 配信: 公開版起動時に同一オリジンの `data/master-catalog.json` を確認する。`verified` の項目だけを対象にし、地域・年度・形式とSHA-256が一致したマスターだけをブラウザー内へ追加する。
- 将来年度: カタログに検証済み年度が追加された後は自動取得する。行政サイトから未監査データを直接取り込まない。
- 利用者マスター: 手動読込み・編集は許可するが `user-supplied` と明示し、検証済み扱いにしない。
- 表示: 県差分未確認時は「全国標準参考」とし、県独自歩掛、労務・材料・市場・機械単価、補正、適用通知が未反映であることを画面・提出前チェック・積算条件書に表示する。
- 証拠: `app.js`、`index.html`、`data/national-standard-masters.js`、`data/prefectures.js`、`data/master-catalog.json`、`tests/test-nationwide-standard.js`、`tests/test-master-catalog.js`、ローカルHTTP実ブラウザー確認。
- 未検証: 徳島県・広島県以外45都道府県の県独自差分。全国標準参考で計算可能であることを、全都道府県の金額検証完了と解釈しない。

## D-009 国直轄と都道府県を分離し、検証状態を段階表示する

- 状態: **検証済み（発注機関分離と表示）**
- 判断: 国土交通省（直轄）は47都道府県とは別の発注機関として選択する。令和6・7・8年度の国交省公開基準・技術者単価によるマスターは「全国標準参考」とし、地域原資料まで照合した「県版検証済み」と区別する。
- 用語変更: 旧表示「公開基準参照・要確認」は「全国標準参考」へ統一した。要確認事項は検証状態欄と提出前チェックに残す。
- 理由: 国土交通省自身が適用時期等を各発注機関（地方整備局等）へ確認するよう案内しており、各県も国準拠、県独自全編、県補足、市販版、CD貸出など運用が異なる。別発注機関の値を無条件に複製すると、未検証データを完全版と誤認させるため。
- 証拠: 国土交通省「設計業務等標準積算基準書および同（参考資料）」令和8年度欄、同「令和8年3月から適用する設計業務委託等技術者単価」、北海道・宮城県・山形県・徳島県の公式積算基準公開案内、`app.js`、`data/prefectures.js`、`tests/test-ui-static.js`、`tests/test-master-catalog.js`
- 検証範囲: 発注機関48件、全都道府県の令和6・7・8年度選択、国交省全国標準参考の選択、警告表示、公式出典リンク、県版検証済みの優先選択。
- 未検証: 地方整備局等の全運用、徳島県以外46都道府県の完全マスター、匿名化済み正解積算との金額一致。

## D-010 過去年度は歩掛・率・単価を同一年度で一体管理する

- 状態: **検証済み（広島県・令和6～8年度）**
- 判断: 過去年度は技術者単価だけを差し替えず、公式積算基準書本体・参考資料・技術者単価を年度単位で組み合わせた別マスターとして配信する。
- 年度差: 広島県の令和6年度諸経費率は91.2％／A=371.23／b=-0.107／51.7％、令和7・8年度は95.8％／A=288.50／b=-0.084／61.4％。直接経費率108行も年度ごとに別値で、令和8年度はUAVレーザ歩掛が改定されている。
- 収録: `r6-hiroshima-2024`、`r7-hiroshima-2025`、`r8-hiroshima-2026`。134項目、直接経費率108行、同年度技術者単価、旅費、安全費、電子成果品作成費を収録する。
- 配信: JSONカタログとローカル用JavaScriptバンドルを同じ生成物から作り、両者の完全一致とSHA-256を試験する。
- 証拠: 広島県公式の令和6・7・8年度積算基準書・参考資料、国土交通省の各年度技術者単価、`data/official-source-catalog.json`、`data/source-audits/hiroshima-r6-r8-expense-rates.json`、`tests/test-hiroshima-masters.js`、実ブラウザー確認。
- 限界: 航空運航費、成果検定費、案件固有条件、特記仕様、後日公表される正誤表は別途確認する。匿名化済み正解積算との全費目一致は未検証であり、公式発注者ソフト相当を保証しない。
