起動方法
--------
「index.html」をダブルクリックしてください。インストールは不要です。
Microsoft Edge / Google Chrome の最新版を推奨します。

初期収録
--------
・国土交通省公表資料を土台にした令和6～8年度の全国標準単価セット（各134項目）
  （直接経費率表108項目＋共通打合せ・別途算定項目26項目）
・見積提出先として全国47都道府県を選択可能（提出先を変えても単価セットは変わりません）
・令和6～8年度の設計7職階、測量・航空船舶10職種、地質3職階の技術者単価
・令和6～8年度の設計・調査計画・地質の職種別標準歩掛735表
・国土交通省の年度別掲載資料24件をURL、ページ数、SHA-256付き原資料台帳として収録
・令和4～5年度の測量・航空船舶10職種の技術者単価記録
・直接経費率（機械、通信運搬、材料）
・精度管理費、電子成果品作成費、安全費、諸経費
・有効4桁、円未満切捨て、業務価格の千円止め

基本操作
--------
1. 起動時は常に空の新規画面です。前回の自動保存データがある場合は、画面上部の「前回データを復元」を押したときだけ復元します。
2. 「見積提出先」は必要な場合だけ選び、「標準単価セット」で令和6・7・8年度を選びます。
3. 上部の「設計業務」「測量業務」「調査・計画業務」「地質業務」から対象業務を選びます。航空写真・航空レーザ・UAV・深浅測量は測量業務の作業分類から選びます。
4. 数量、地域・地形等の規定条件を選択します。複合地域は加重平均した変化率を手動追加します。
5. 旅費は「宿泊なし0.56%」「宿泊あり0.83%」「実費積上げ」から選びます。
6. 往復経費、基地費、成果検定費等を入力します。
7. 各明細の「計算根拠を見る」で、標準直接費、1単位当り単価、直接作業費、精度管理費の式を確認します。
8. 右側の「提出前チェック」で、適用範囲外・別途算定単価・手動変化率を確認します。
9. 「積算書を保存」でJSON、「CSV出力」で表形式を保存します。
10. 「帳票・PDF」で宛先・自社情報・条件と出力帳票を選び、「PDFプレビュー・印刷」を押します。
   印刷画面のプリンターで「PDFに保存」を選ぶと、お客様提出用PDFになります。

4業務タブ
---------
業務入力は「設計業務」「測量業務」「航空・船舶関係」「地質業務」の順に分けています。

・設計業務：土木設計、調査・計画
・測量業務：共通、基準点、水準、路線、河川、用地、現地測量
・航空・船舶関係：深浅、空中写真、航空レーザ、UAV・地上レーザ測量
・地質業務：地質解析等調査、地質一般調査

設計業務、測量業務、調査・計画業務、地質業務は画面を分けていますが、保存データと総合積算結果は同じ案件内で管理します。
航空写真・航空レーザ・UAV・地上レーザ・深浅測量は、作業規程上の分類に従って測量業務に含めます。港湾、航空局・空港等の別積算基準を同じ項目として扱うものではありません。
令和6・7・8年度を切り替えると、国土交通省公表の設計7職階・地質3職階の日額が同時に切り替わります。

・土木設計、調査・計画、地質解析等：直接人件費からその他原価と一般管理費等を計算する設計方式
・地質一般調査：直接調査費と間接調査費の対象額から諸経費率を計算する地質調査方式
・現在の測量積算：必要な場合だけ税抜の測量業務価格を合算し、消費税を最後に一度だけ計算

作業名、職種、人工を個別入力できるほか、現在年度・業務タブに対応する「年度別標準歩掛」を検索して追加できます。
標準歩掛は原表の標準単位、出典ページ、職種別人工を表示します。原表の数量式・適用条件から算定した補正係数を小数第2位まで入力して追加し、補正後人工は小数第3位までとします。補正係数を空欄のまま1倍として追加しません。
機械・材料・運搬・仮設・市場単価、旅費、案件固有補正は標準歩掛だけでは決まらないため、積上げ費用へ入力し原資料と照合してください。
「総合内訳をPDF出力」から、総合積算総括表と業務費内訳書をA4 PDFにできます。

PDF・写真から積算取込
----------------------
「PDF・写真取込」では、PDF、PNG、JPEG、WebPから測量数量と設計・調査・地質の人工候補を作成します。
文字情報を持つPDFは直接抽出し、文字を持たないPDFページと写真だけ日本語OCRを使用します。

1. 資料をドロップまたは選択します。最大30MB、PDFは1回60ページまでです。
2. 業務名、発注者、担当部署・担当者、業務場所、履行期間、文書番号、公告等の日付、測量作業・数量、設計等の業務区分・作業名・職種・人工、積上費用候補を解析します。
3. 「抽出結果の確認・修正」で、元の文章、ページ番号、抽出方法、確信度と候補を照合します。
4. 誤った項目、数量、職種、人工をその場で修正し、不要な候補のチェックを外します。
5. 「確認した項目を積算へ反映」を押した項目だけが積算データになります。

OCRは「8」を「⑧」、「4級」を「4紐」などと誤認することがあります。丸数字と日本語文字間隔は
自動補正しますが、低確信度候補は初期選択せず、金額候補も誤計上防止のため初期選択しません。
通常の業務基本情報は項目ごとに選択して反映できます。発注者は帳票の宛名、履行期間は帳票の納期にも反映します。
見積提出先は帳票情報であり金額へ影響しません。資料年度を反映する場合だけ、全国標準単価セットの年度切替を再確認します。

解析はブラウザー内で実行します。OCR時は解析プログラムと日本語言語データをインターネットから
取得しますが、選択したPDF・写真そのものを外部サーバーへアップロードする処理はありません。

提出用帳票・PDF
----------------
次の5帳票を選択して、1つのA4 PDFにまとめられます。
・見積書：宛名、見積番号、件名、税込金額、税抜額・消費税、納期、支払条件、有効期限、発行者
・積算総括表：直接人件費、直接経費、精度管理費、旅費等、諸経費、業務価格、消費税
・業務費内訳書：作業項目、数量、単位、単価、直接作業費、精度管理費込み金額、分類小計
・単価・歩掛内訳書：標準人件費、機械・通信・材料、標準直接費、補正係数、採用単価、出典頁
・積算条件書：歩掛・単価年度、端数処理、旅費、安全費、消費税、要確認事項、マスター出典

通常のお客様提出には「お客様向け3帳票」（見積書・積算総括表・業務費内訳書）、
根拠説明や社内検算には「全帳票」を使用します。入力画面、操作ボタン、警告パネルはPDFに出ません。
長い内訳は自動改ページし、各ページで表見出しを繰り返します。

推奨印刷設定：A4、倍率100%、背景のグラフィックON。
発注機関が指定様式やExcel提出を求める案件では、その指定を優先してください。

年度単価の更新
--------------
測量積算は、令和6～8年度の国土交通省・全国標準単価セットを切り替えます。
見積提出先は全国47都道府県から選べますが、提出先を変えても計算単価は変わりません。
設計業務・地質業務は、令和6～8年度の技術者単価と業務区分別計算方式を切り替えます。

将来年度は、公式資料の単価・歩掛・率・適用日・端数規定を検証してから追加してください。
単価だけを翌年度へ差し替えたものを完全な年度マスターとして扱わないでください。

歩掛・経費率まで改定された年度は、マスターJSON内の roles、workItems、
overhead、electronicDeliverable、safetyRates を年度資料に合わせて変更し、
「マスター読込み」で登録できます。

データ保存について
------------------
入力中の積算と単価セットはブラウザーのローカルストレージに自動保存されます。
次回起動時に前回データを勝手に表示せず、新規画面と復元案内を表示します。
「前回データを復元」を押した場合だけ自動保存データを読み込みます。「読込」はJSONファイル用です。
ブラウザーの閲覧データを削除すると消えるため、重要な積算書・年度マスターは
必ずJSONで書き出して別途保管してください。

重要：標準総額と単価
--------------------
例「2級基準点測量 新点10点 伐採有り」の令和8年度初期値は、標準10点の直接費が
3,448,507円、1点当りの有効4桁単価が344,800円、10点を計上した直接作業費が
3,448,000円です。344,800円は10点総額ではありません。画面では両方を併記します。

計算上の注意
------------
・点、箇所、回、機関、業務、戸、人、測線、断面、本、枚、日、m²は整数のみ入力できます。
・km、km²、時間は小数第3位まで入力できます。第4位以下は計算に使用しません。
・キーボード、上下ボタン、貼り付け、積算書JSON読込みのすべてに同じ数量規則を適用します。
・深浅測量は水面幅の補正式、現地測量は面積による作業量補正式を自動適用します。
・地域・地形・交通量・曲線数・縮尺等は、該当工程に規定選択肢を表示します。
・適用範囲を外れた数量は警告します。範囲外は比例計算を正解扱いせず、別途積算してください。
・航空写真・航空レーザの総運航、撮影、計測等は飛行場・高度・機種等で決まるため、
  基準書の運航式で算定した単価を「入力単価」へ入れます。
・レベル500、UAVレーザ等で基準書が機械経費・精度係数を「別途計上」とする項目は、
  画面に要確認警告を表示します。未入力の0円を確定額として使用しないでください。

実際の設計書に使う前に、発注者の当該年度版基準書、特記仕様書、既存の正解積算例と
必ず照合してください。マスターの作成者・更新日・根拠資料も一緒に保管することを推奨します。

テスト
------
Node.jsがある場合、tests フォルダーの test-engine.js を実行すると、端数処理、
諸経費、電子成果品、旅費、精度管理費、作業量補正式、特殊機械経費式、代表歩掛の
固定値テストを実行できます。
test-role-prices.js では、令和4～8年度の公式技術者単価セットを検査します。
test-ui-static.js では、数量入力制限、5種類の帳票生成、A4印刷設定、表見出しの繰返しを検査します。
test-document-import.js では、PDF文字配置、OCR丸数字、縮尺と数量の分離、測量数量、設計・地質人工、
低確信度金額候補を検査します。test-document-import-ui.js では、確認・修正画面と安全な反映経路を検査します。
test-official-case-engine.js では、公式API XML解析、案件一致度、資料分類、危険URLの除外を検査します。
test-official-case-ui.js では、廃止した公式案件検索UIが表示されず、旧保存データ互換だけが残ることを検査します。

令和8年度PDFとの機械照合
--------------------------
令和8年度基準書の「各費目の直接人件費に対する割合」108行を独立抽出し、
マスターの機械経費率・通信運搬費等率・材料費率と全コード照合しています。
照合結果は108行一致、不一致0件です。
