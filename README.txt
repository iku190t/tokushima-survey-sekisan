測量積算ワークベンチ
====================

起動方法
--------
「index.html」をダブルクリックしてください。インストールは不要です。
Microsoft Edge / Google Chrome の最新版を推奨します。

初期収録
--------
・令和8年度 徳島県の測量積算基準をもとにした積算項目 134項目
  （直接経費率表108項目＋共通打合せ・別途算定項目26項目）
・令和8年3月適用の設計業務委託等技術者単価 10職種
・国土交通省公表の令和4～8年度 技術者単価 10職種（年度切替・比較用）
・直接経費率（機械、通信運搬、材料）
・精度管理費、電子成果品作成費、安全費、諸経費
・有効4桁、円未満切捨て、業務価格の千円止め

基本操作
--------
1. 起動時は常に空の新規画面です。前回の自動保存データがある場合は、画面上部の「前回データを復元」を押したときだけ復元します。
2. 「積算」画面で業務名と作業項目を選びます。
3. 数量、地域・地形等の規定条件を選択します。複合地域は加重平均した変化率を手動追加します。
4. 旅費は「宿泊なし0.56%」「宿泊あり0.83%」「実費積上げ」から選びます。
5. 往復経費、基地費、成果検定費等を入力します。
6. 各明細の「計算根拠を見る」で、標準直接費、1単位当り単価、直接作業費、精度管理費の式を確認します。
7. 右側の「提出前チェック」で、適用範囲外・別途算定単価・手動変化率を確認します。
8. 「積算書を保存」でJSON、「CSV出力」で表形式を保存します。
9. 「帳票・PDF」で宛先・自社情報・条件と出力帳票を選び、「PDFプレビュー・印刷」を押します。
   印刷画面のプリンターで「PDFに保存」を選ぶと、お客様提出用PDFになります。

提出用帳票・PDF
----------------
次の5帳票を選択して、1つのA4 PDFにまとめられます。
・見積書：宛名、見積番号、件名、税込金額、税抜額・消費税、納期、支払条件、有効期限、発行者
・積算総括表：直接人件費、直接経費、精度管理費、旅費等、諸経費、業務価格、消費税
・業務費内訳書：作業項目、数量、単位、単価、直接作業費、精度管理費込み金額、分類小計
・単価・歩掛内訳書：標準人件費、機械・通信・材料、標準直接費、補正係数、採用単価、出典頁
・積算条件書：歩掛・単価年度、端数処理、旅費、安全費、消費税、要確認事項、マスター出典

通常のお客様提出には「お客様向け3帳票」（見積書・積算総括表・業務費内訳書）、
根拠説明や社内検算には「全帳票」を使用します。入力画面、操作ボタン、警告パネルはPDFに出ません。
長い内訳は自動改ページし、各ページで表見出しを繰り返します。

推奨印刷設定：A4、倍率100%、背景のグラフィックON。
発注機関が指定様式やExcel提出を求める案件では、その指定を優先してください。

年度単価の更新
--------------
「年度・単価マスター」には、国土交通省が公表した令和4～8年度の技術者単価を収録しています。
年度を選び「この単価で複製」を押すと、選択した公式単価を使う編集用マスターを作成します。

重要：令和4～7年度の初期選択肢は「令和8年度歩掛＋過去年度技術者単価」の比較試算です。
過去年度の正式積算には、当該年度の歩掛・直接経費率・精度管理費係数・諸経費式・端数処理を
収録した完全マスターが別途必要です。画面にも比較用であることを警告表示します。

翌年度候補の作成は「翌年度候補を複製」を使えますが、複製だけで正式マスターにはなりません。
年度資料による全項目の差分確認後、「マスター書出し」でJSONを保管してください。

歩掛・経費率まで改定された年度は、マスターJSON内の roles、workItems、
overhead、electronicDeliverable、safetyRates を年度資料に合わせて変更し、
「マスター読込み」で登録できます。

データ保存について
------------------
入力中の積算と年度マスターはブラウザーのローカルストレージに自動保存されます。
次回起動時に前回データを勝手に表示せず、新規画面と復元案内を表示します。
「前回データを復元」を押した場合だけ自動保存データを読み込みます。「読込」はJSONファイル用です。
ブラウザーの閲覧データを削除すると消えるため、重要な積算書・年度マスターは
必ずJSONで書き出して別途保管してください。

重要：標準総額と単価
--------------------
例「2級基準点測量 新点10点 伐採有り」の令和8年度初期値は、標準10点の直接費が
3,448,507円、1点当りの有効4桁単価が344,800円、10点を計上した直接作業費が
3,448,000円です。344,800円は10点総額ではありません。画面では両方を併記します。

計算上の注意
------------
・点、箇所、回、機関、業務、戸、人、測線、断面、本、枚、日、m²は整数のみ入力できます。
・km、km²、時間は小数第3位まで入力できます。第4位以下は計算に使用しません。
・キーボード、上下ボタン、貼り付け、積算書JSON読込みのすべてに同じ数量規則を適用します。
・深浅測量は水面幅の補正式、現地測量は面積による作業量補正式を自動適用します。
・地域・地形・交通量・曲線数・縮尺等は、該当工程に規定選択肢を表示します。
・適用範囲を外れた数量は警告します。範囲外は比例計算を正解扱いせず、別途積算してください。
・航空写真・航空レーザの総運航、撮影、計測等は飛行場・高度・機種等で決まるため、
  基準書の運航式で算定した単価を「入力単価」へ入れます。
・レベル500、UAVレーザ等で基準書が機械経費・精度係数を「別途計上」とする項目は、
  画面に要確認警告を表示します。未入力の0円を確定額として使用しないでください。

実際の設計書に使う前に、発注者の当該年度版基準書、特記仕様書、既存の正解積算例と
必ず照合してください。マスターの作成者・更新日・根拠資料も一緒に保管することを推奨します。

テスト
------
Node.jsがある場合、tests フォルダーの test-engine.js を実行すると、端数処理、
諸経費、電子成果品、旅費、精度管理費、作業量補正式、特殊機械経費式、代表歩掛の
固定値テストを実行できます。
test-role-prices.js では、令和4～8年度の公式技術者単価セットを検査します。
test-ui-static.js では、数量入力制限、5種類の帳票生成、A4印刷設定、表見出しの繰返しを検査します。

令和8年度PDFとの機械照合
--------------------------
令和8年度基準書の「各費目の直接人件費に対する割合」108行を独立抽出し、
マスターの機械経費率・通信運搬費等率・材料費率と全コード照合しています。
照合結果は108行一致、不一致0件です。
